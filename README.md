# Hollow Wilds

เดโมเกมเอาชีวิตรอดแบบ 2D top-down ในไฟล์ `index.html` ไฟล์เดียว (HTML + CSS + JavaScript + Canvas)
ไม่ใช้ไลบรารีหรือรูปภาพภายนอก ทุกอย่างวาดด้วยโค้ด ลายเส้นสเก็ตช์โทนมืดแบบ gothic

## วิธีเล่น

เปิด `index.html` ในเบราว์เซอร์ คลิกบนจอเกมหนึ่งครั้ง แล้วเริ่มเล่นได้เลย

| ปุ่ม | การกระทำ |
| --- | --- |
| W A S D / ลูกศร | เดิน |
| E | เก็บไม้ หญ้า หิน เบอร์รี่ / เติมไม้ให้กองไฟ |
| F | กินเบอร์รี่ |
| C | ก่อกองไฟ (ไม้ 3 + หญ้า 2) |
| X | คราฟหรือซ่อมขวานหิน (หิน 2 + ไม้ 2) |
| คลิกซ้าย | ฟันไปทางเมาส์ |
| Space | ฟันแมงมุมตัวที่ใกล้ที่สุด |
| R | เริ่มใหม่หลัง Game Over |

## ระบบในเกม

- แถบสถานะ 3 อัน: พลังชีวิต ความอิ่ม และสติ
- วงจรวัน 2 นาที (กลางวัน · ยามเย็น · กลางคืน) พร้อมนาฬิกาและตัวนับ Day
- กลางคืนมืดสนิท เห็นได้แค่ในแสงกองไฟ ถ้าอยู่ในความมืดนานเกินไปจะเสียเลือด
- แมงมุมตาเดียวออกล่าตอนกลางคืนและกลัวแสงไฟ
- ฆ่าแมงมุมครบ 6 ตัว ราชินีแมงมุมตาเดียว (บอส) จะปรากฏตัว
- ขวานหินเพิ่มดาเมจและได้ไม้มากขึ้นต่อการตัดหนึ่งครั้ง
